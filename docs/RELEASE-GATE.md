# v1.0 发布前人工审核

2026-10-22 用户新增要求：在定版 v1.0 和上传 GitHub 之前，在用户手机上卸载旧测试应用，安装最新候选应用，交由用户手动审核。**只有用户明确审核通过后才能定版和公开上传。** 此要求取代此前的自动完成后直接发布授权。

1. 完成实现、自动测试和兼容性检查，整理真实测试结果与未覆盖项。
2. 备份旧测试包中的用户录音与本地数据。原始数据仅保存在本机忽略目录，不进入公开仓库。
3. 卸载旧 PoC、Debug 及对应测试包；安装采用正式安装身份和独立发布证书的 `1.0-rc.1` 候选包。
4. 向用户提供简短的手动验收清单与已知限制，等待用户明确通过。
5. 若有问题，修复并覆盖安装新的候选版本，再次审核。
6. 通过后使用同一证书构建 `1.0`（versionCode 10000），覆盖安装、复核文件摘要，整理 Git 历史、许可及公开材料。
7. 最后新建公开仓库 `KokoroLyase/Koenami-For-Android`，推送源码与标签，上传签名 APK、校验和及 Release 说明。

候选版本 versionCode 9999；同签名的正式 1.0 可直接覆盖升级。开发 Debug 包使用独立安装身份。任何未完成或失败的关键测试均不得标为通过。
