# 开发进度

执行顺序：M0 验证 → M1 容器 → M2 增强基础设施 → M3 训练 → M4 语音库/历史 → M5 系统集成 → M6 验证 → M7 签名交付 → GitHub 公开发布。

- 软件效果沿用原实施规划；应用版本从正式 1.0 开始。
- Git 管理源码；阶段改动单独提交。
- 已获用户批准：在 INTERNET、RECORD_AUDIO、ACCESS_NETWORK_STATE 外增加 MODIFY_AUDIO_SETTINGS，满足 WebView 音频设备选择。
- 原型数据与正式包数据隔离，不自动迁移官网私有数据库。
- 官方网站、服务和音频仍由官方提供；不引入本地前端、分析代理或替代算法。
- 未通过的测试不标为通过；尚未满足发布条件时不推送公开仓库或正式 Release。
