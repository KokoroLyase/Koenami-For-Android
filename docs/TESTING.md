## 复现入口

- `./gradlew lintDebug testDebugUnitTest assembleDebug`（Windows 用 gradlew.bat）。
- `connectedDebugAndroidTest`：设备需解锁并允许安装；官网联网测试可能受官网变更影响。
- 在自有 Debug WebView 的 DevTools socket 上建立本机 adb forward 后，运行 `node tools/layout-qa.mjs` 或 `node tools/bottom-layout-qa.mjs`；原始结果写入忽略的 evidence 目录。
- 设备测试使用独立测试 APK，正式交付不携带测试包或任意 JS 执行接口。
