# 隐私、权限与数据

客户端没有自己的训练服务器、账户、广告或统计 SDK，不自动上传诊断日志。它加载真实官网，官网 API、资源和原有统计请求仍会发生；参考音频及来源链接可能涉及第三方站点。客户端不承诺官网联网行为永不变化。

录音、分析和收藏由官网代码处理。审阅基线使用官网本地音频链路分析，将已提交历史存入 WebView 站点数据库。客户端不增加音频上传接口，也不复制或写入官网私有数据库结构。

| 权限 | 用途 |
|---|---|
| INTERNET | 官网、资源、参考音频及官网 API |
| ACCESS_NETWORK_STATE | 网络状态能力 |
| RECORD_AUDIO | 用户操作及系统授权后由 WebView 使用麦克风 |
| MODIFY_AUDIO_SETTINGS | 满足 Chromium 音频设备选择；客户端不强制指定设备 |

音频设置权限经真机 A/B 验证后加入：缺少时 Chromium 报 `Unable to select communication device`，增加后普通录音恢复。不申请摄像头、定位或广泛存储权限。麦克风授权校验受信任来源、前台状态和当前会话，摄像头、定位及未知资源被拒绝。

导入只接收系统选择器返回的 `content://` URI。导出先进入私有缓存，由用户选择保存或 Android 分享，不自动发送给他人。分享通过 FileProvider 临时授予读取权限；后续启动时清理超过 24 小时的分享缓存。卸载删除私有缓存。

站点数据位于应用私有目录，系统备份和自动迁移被禁用。卸载、清除数据会删除录音历史。原始和优化模式共用当前包的站点数据；PoC / Debug / 正式包不同安装身份不共用历史。官网 ZIP 不是完整数据库恢复包。

进入后台请求官网停止采集，保存结果请在历史中确认；异常终止、权限撤回或进程回收可能丢失未提交采集。重要音频应定期导出到应用之外。

公开仓库不收集用户录音、原始截图、系统日志、设备标识或密钥。提交 Issue 前请去除个人信息；兼容性诊断仅在本机显示，不自动上报。
